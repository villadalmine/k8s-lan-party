k8s-lan-party looks like a game, but each thing you see in it is a platform engineering concept running end to end. This page says, for each feature, **what the concept is**, **an everyday analogy**, **where it is used for real**, **where you see it** and **which suite steps prove it**.

The last column is not decoration: `make regression` runs those steps in a fixed order and writes the same table every time ([POC-STATUS.md](POC-STATUS.md)), so a row here is a claim a test checks, not a story. The concepts are those of a Kubernetes platform engineer: admission, tenancy, placement, network policy, revocation.
